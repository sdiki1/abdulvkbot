# VK-бот Натальи Щаповой

Чат-бот сообщества ВКонтакте на Bots Long Poll API. Реализованы главное меню, все четыре ветки из сценария, сбор заявок, уведомления администраторам и реактивация через 6/24/72 часа.

## Запуск

1. В настройках сообщества ВК включите **Сообщения** и **Long Poll API**, события `Входящее сообщение`.
2. Создайте ключ доступа сообщества с правом управления сообщениями.
3. Подготовьте окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

4. Заполните `.env` и запустите:

```bash
python bot.py
```

Бот хранит диалоги, историю сообщений и заявки в SQLite. Команды `меню`, `начать`, `старт` и `/start` возвращают пользователя в начало. Для заявки имя и телефон отправляются одним текстовым сообщением.

## Админ-панель

Укажите в `.env` отдельные данные для входа:

```dotenv
ADMIN_LOGIN=admin
ADMIN_PASSWORD=сложный-пароль
ADMIN_SECRET_KEY=длинная-случайная-строка
ADMIN_HOST=127.0.0.1
ADMIN_PORT=8080
```

Запустите панель в отдельном процессе рядом с ботом:

```bash
source .venv/bin/activate
python admin.py
```

Откройте `http://127.0.0.1:8080`. В панели доступны:

- общая статистика, активность за 14 дней и конверсия;
- поиск и фильтрация пользователей;
- история переписки и отправка сообщения пользователю;
- список заявок и контактов;
- изменение текстов бота без перезапуска;
- ручная отметка конверсии пользователя.

При размещении в интернете используйте HTTPS и не оставляйте стандартный пароль. Чтобы открыть панель с другого компьютера, задайте `ADMIN_HOST=0.0.0.0` и ограничьте доступ через firewall или reverse proxy.

## Настройки

- `VK_GROUP_TOKEN` — токен сообщества (обязательно).
- `VK_GROUP_ID` — числовой ID сообщества (обязательно).
- `ADMIN_VK_IDS` — ID администраторов через запятую; им приходят новые заявки.
- `DIKIDI_URL`, `EVENTS_URL`, `REPORTS_URL` — рабочие ссылки.
- `DB_PATH` — путь к SQLite базе.
- `ADMIN_LOGIN`, `ADMIN_PASSWORD` — данные входа в панель.
- `ADMIN_SECRET_KEY` — случайная секретная строка для защиты сессий.

Для остановки используйте `Ctrl+C`. Реактивация проверяется раз в минуту и не отправляется после заявки или перехода по ссылке записи.

## Запуск через Docker Compose

Установите Docker, затем создайте конфигурацию:

```bash
cp .env.example .env
```

Заполните в `.env` как минимум `VK_GROUP_TOKEN`, `VK_GROUP_ID`, `ADMIN_LOGIN`, `ADMIN_PASSWORD` и `ADMIN_SECRET_KEY`. После этого запустите бота и панель:

```bash
docker compose up -d --build
```

Админ-панель будет доступна по адресу `http://localhost:8080`. Если порт 8080 занят, измените внешний порт:

```dotenv
ADMIN_PUBLISHED_PORT=8090
```

Полезные команды:

```bash
# Посмотреть состояние контейнеров
docker compose ps

# Смотреть логи
docker compose logs -f bot admin

# Перезапустить сервисы
docker compose restart

# Остановить, сохранив базу
docker compose down
```

SQLite хранится в Docker volume `bot_data` и не удаляется командой `docker compose down`. Команда `docker compose down -v` удалит volume вместе с базой данных.
