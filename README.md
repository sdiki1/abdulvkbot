# VK-бот Натальи Щаповой

Чат-бот сообщества ВКонтакте на Bots Long Poll API. Реализованы главное меню, все четыре ветки из сценария, сбор заявок, уведомления администраторам и реактивация через 6/24/72 часа (интервалы настраиваются).

## Сценарий

Главное меню: остеопатия, ароматестирование, комплексная программа, ближайшие мероприятия.

Ветка «Остеопатия» ведёт человека по шагам: выбор проблемы → сочувственный ответ под конкретную жалобу → рассказ о себе (путь, специализация, истории пациентов) → как проходит приём → работа с возражениями → запись. Кнопки «Записаться на первый приём», «Все услуги и пакеты» и «Аудиоконсультация 5 минут» продублированы на всех шагах и работают из любого места диалога.

Запись ведёт на разные ссылки Dikidi в зависимости от города: Москва — `DIKIDI_MOSCOW_URL`, Звенигород — `DIKIDI_ZVENIGOROD_URL`. После слова «ЗАПИСАЛСЯ» бот присылает промокод `ПЕРВЫЙ15`.

Реактивация: через 6 часов — напоминание с промокодом, через 24 часа — история пациента, подобранная под тему диалога, через 72 часа — приглашение на бесплатный мастер-класс.

## Запуск

1. В настройках сообщества ВК включите **Сообщения** и **Long Poll API**, события `Входящее сообщение`.
2. Создайте ключ доступа сообщества с правом управления сообщениями.
3. Подготовьте окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

4. Заполните `.env` и запустите:

```bash
python bot.py
```

Бот хранит диалоги, историю сообщений и заявки в SQLite. Команды `меню`, `начать`, `старт` и `/start` возвращают пользователя в начало. Для заявки имя и телефон отправляются одним текстовым сообщением.

## Админ-панель

Укажите в `.env` отдельные данные для входа:

```dotenv
ADMIN_LOGIN=admin
ADMIN_PASSWORD=сложный-пароль
ADMIN_SECRET_KEY=длинная-случайная-строка
ADMIN_HOST=127.0.0.1
ADMIN_PORT=8888
```

Запустите панель в отдельном процессе рядом с ботом:

```bash
source .venv/bin/activate
python admin.py
```

Откройте `http://127.0.0.1:8888`. В панели доступны:

- общая статистика, активность за 14 дней, конверсия и воронка по этапам сценария;
- поиск и фильтрация пользователей, в том числе по этапу диалога;
- история переписки и отправка сообщения пользователю;
- заявки со статусами «Новая / В работе / Записан / Отказ» и заметками;
- выгрузка пользователей и заявок в CSV (открывается в Excel);
- изменение всех настроек из `.env` прямо в браузере;
- изменение текстов бота без перезапуска.

При размещении в интернете используйте HTTPS и не оставляйте стандартный пароль. Чтобы открыть панель с другого компьютера, задайте `ADMIN_HOST=0.0.0.0` и ограничьте доступ через firewall или reverse proxy.

## Настройки

Все параметры можно менять в разделе «Настройки» админ-панели: значения сохраняются в базу и дублируются в файл `.env`, если он доступен на запись. Настройка, сохранённая в панели, важнее значения из `.env`; чтобы вернуть управление файлу, очистите поле.

- `VK_GROUP_TOKEN` — токен сообщества (обязательно, нужен перезапуск бота).
- `VK_GROUP_ID` — числовой ID сообщества (обязательно, нужен перезапуск бота).
- `DIKIDI_MOSCOW_URL`, `DIKIDI_ZVENIGOROD_URL` — ссылки на запись по городам, `DIKIDI_URL` — запасная.
- `EVENTS_URL`, `REPORTS_URL` — мероприятия и отчёты о встречах.
- `ADMIN_VK_IDS` — ID администраторов через запятую; им приходят новые заявки.
- `REACTIVATION_HOURS` — через сколько часов отправлять три напоминания, по умолчанию `6,24,72`.
- `DB_PATH` — путь к SQLite базе (нужен перезапуск бота и панели).
- `ADMIN_LOGIN`, `ADMIN_PASSWORD` — данные входа в панель.
- `ADMIN_SECRET_KEY` — случайная секретная строка для защиты сессий.
- `LOG_LEVEL` — уровень логов бота.

Ссылки, получателей заявок, интервалы напоминаний и уровень логов бот подхватывает в течение минуты без перезапуска. Токен, ID сообщества и путь к базе требуют рестарта — панель отмечает такие поля.

База данных хранит настройки, включая пароль панели и токен сообщества, поэтому доступ к файлу `bot.sqlite3` должен быть ограничен так же, как к `.env`.

Для остановки используйте `Ctrl+C`. Реактивация проверяется раз в минуту и не отправляется после заявки или перехода по ссылке записи.

## Запуск через Docker Compose

Установите Docker, затем создайте конфигурацию:

```bash
cp .env.example .env
```

Заполните в `.env` как минимум `VK_GROUP_TOKEN`, `VK_GROUP_ID`, `ADMIN_LOGIN`, `ADMIN_PASSWORD` и `ADMIN_SECRET_KEY`. После этого запустите бота и панель:

```bash
docker compose up -d --build
```

Админ-панель будет доступна по адресу `http://localhost:8888`. Если порт 8888 занят, измените внешний порт:

```dotenv
ADMIN_PUBLISHED_PORT=8090
```

Полезные команды:

```bash
# Посмотреть состояние контейнеров
docker compose ps

# Смотреть логи
docker compose logs -f bot admin

# Перезапустить сервисы
docker compose restart

# Остановить, сохранив базу
docker compose down
```

SQLite хранится в Docker volume `bot_data` и не удаляется командой `docker compose down`. Команда `docker compose down -v` удалит volume вместе с базой данных.
